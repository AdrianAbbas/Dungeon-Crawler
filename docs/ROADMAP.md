# Roadmap

## 1.0 (frozen)

DUNGEON CRAWLER 1.0.0 is released and frozen ([CHANGELOG.md](../CHANGELOG.md)). From now on
1.0.x takes **bug fixes only**: crashes, validation failures, wrong or broken sound against
1.0.0, installer problems. No new features, sounds, places, presets or interface changes go
into 1.0.x, and a fix must leave projects saved with 1.0.0 sounding the same.
